Sistema de monitoramento térmico para tanques de trutas. O projeto resolve um problema real de piscicultura, utilizando sensores para garantir que a temperatura da água permaneça em níveis ideais.

## 🛠️ Stack Técnica
- **Hardware:** Arduino + Sensor de Temperatura (DS18B20).
- **Backend:** Node.js com Express (API de recepção de dados).
- **Banco de Dados:** MySQL (SQL Server para consultas estruturadas).
- **Frontend:** JavaScript e Charts.js para exibição de gráficos em tempo real.

## 📊 Diferenciais
- Coleta automática de dados via sensores físicos.
- Dashboard dinâmico para tomada de decisão rápida.
